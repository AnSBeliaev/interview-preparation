# Подготовка к собеседованию

Уровень на собеседовании: **junior**. Стек: **Python + SQL**.
Ваш опыт: **React, TypeScript, JavaScript, 4+ года**.

Из старшей методички в эти выходные берём только четыре куска:

- JSON и XML целиком
- Git целиком
- ETL и ELT на уровне понимания
- индексы: только B-tree и GIN под JSONB

Остальное из той методички (планы запросов, Kafka, gRPC, витрины ClickHouse в деталях) в этот заход не учим.

Сегодня воскресенье. Скрипты на Python пишут в таблицы, которые собираются в субботнем блоке. Если субботы ещё не было, утром закройте сжатую субботу, потом идите по воскресенью.

Перед практикой поставьте две программы: их сейчас нет в системе. Docker Desktop нужен для субботней базы, Python 3 с галочкой Add to PATH — для воскресенья. Куда нажимать, написано в начале [суббота-практика-docker.md](суббота-практика-docker.md) и [06-python-для-фронтенда.md](06-python-для-фронтенда.md). Пока они ставятся, читайте типы и DDL.

## Полный план, если оба дня на месте

### Суббота

| Блок | Файл |
| --- | --- |
| Типы PostgreSQL и DDL | [02-sql-ddl-типы.md](02-sql-ddl-типы.md) |
| Postgres в Docker, 4 связанные таблицы, ALTER | [суббота-практика-docker.md](суббота-практика-docker.md) |
| Вечер: запросы, индекс, B-tree, GIN | [03-sql-запросы.md](03-sql-запросы.md) |

Субботний список, который надо закрыть руками:

- целые: `smallint`, `integer`, `bigint`
- дробные: `numeric(p,s)` против `real` / `double precision`, почему деньги в `numeric`
- строки: `varchar(n)`, `text`, `char(n)`
- `boolean`
- `date`, `time`, `timestamp`, `timestamptz`
- `uuid`
- `json` против `jsonb`
- `serial` и `GENERATED ALWAYS AS IDENTITY`
- `PRIMARY KEY`, `FOREIGN KEY` (`ON DELETE CASCADE` / `SET NULL`), `NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`
- `ALTER TABLE`: добавить и удалить колонку, сменить тип, добавить ограничение

Практика:

```bash
docker run --name pg -e POSTGRES_PASSWORD=pass -p 5432:5432 -d postgres
```

Таблицы: клиенты, товары, заказы, позиции заказа.

Вечер: `SELECT`, `WHERE`, `ORDER BY`, `LIMIT`, `JOIN` inner и left, `GROUP BY`, `HAVING`, `count` / `sum` / `avg`, когда индекс помогает и когда нет.
